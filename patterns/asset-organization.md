# Pattern: Asset Organization

## The Problem

AI creates outputs — images, exports, generated files. Without structure:
- Outputs get scattered everywhere
- No context for what each file is
- Later sessions can't find or understand previous work
- Versioning becomes a nightmare

## The Solution

Organize outputs by logical unit (carousel, export, version) with context files.

### 1. Folder Per Output

Don't dump everything in one `output/` folder. Create logical groupings:

```
✅ Good:
tools/carousel-export/
├── carousel1/
│   ├── 1.png
│   ├── 2.png
│   └── captions.md
├── carousel2/
│   └── ...
└── carousel3/
    ├── 1.png
    ├── 2.png
    └── captions.md

❌ Bad:
output/
├── slide1.png
├── slide2.png
├── carousel2-slide1.png
├── old-slide1.png
└── ... chaos
```

### 2. Context Files

Every output folder gets a context file explaining what's in it:

**captions.md** (for social media exports):
```markdown
# Carousel 03 — Scaling Chaos

**Theme:** Business growing but systems didn't
**Angle:** Pain → Reframe → Solution
**CTA:** example.com

## Slide 1
**Visual:** "Your business is growing..."
**Caption:** Growth should feel like progress.

## Slide 2
...
```

**manifest.md** (for general exports):
```markdown
# Export — 2026-04-05

**Source:** src/components/
**What:** Component screenshots for docs
**Generated by:** puppeteer script

## Files
- button.png — Primary button states
- modal.png — Modal component
```

### 3. Numbered Files

Use simple numbered names for sequences:
```
1.png, 2.png, 3.png     ← Simple, sortable
NOT: slide-hook.png, slide-pain.png   ← Hard to sort, verbose
```

Put the meaning in `captions.md`, not the filename.

### 4. Version Folders

For iterations, use versioned folders:
```
carousel-export/
├── carousel3-v1/    ← First version
├── carousel3-v2/    ← After feedback
└── carousel3/       ← Final (no version = current)
```

## How to Implement

Add to your workflow:

1. **Create folder** for each logical output
2. **Name files simply** (numbered or descriptive)
3. **Add context file** (captions.md, manifest.md)
4. **Document in TOOLS-INDEX.md** if it's a tool output

Add to CLAUDE.md:
```markdown
## Asset Organization
- Create folder per output batch
- Include captions.md or manifest.md with context
- Use numbered filenames for sequences
- Keep TOOLS-INDEX.md updated
```

## Common Scenarios

**Social media carousels:**
```
carousel-export/carousel3/
├── 1.png through 6.png
└── captions.md (theme, angle, per-slide captions)
```

**Documentation screenshots:**
```
docs/screenshots/
├── v2.1/
│   ├── dashboard.png
│   ├── settings.png
│   └── manifest.md
```

**Generated reports:**
```
reports/2026-04/
├── summary.pdf
├── data.csv
└── manifest.md
```

## Why This Matters

1. **Future sessions** can understand past work
2. **AI can reference** previous outputs
3. **Human collaborators** get context
4. **No orphaned files** — everything has a home

## Measuring Success

You're doing it right if:
- Any output can be understood without asking
- Folders are self-documenting
- Old exports are still usable months later
- AI can find and reference previous work
